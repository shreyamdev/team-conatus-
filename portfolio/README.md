## 💻 Local Development

To run this project locally, follow these steps:

1. **Clone the repository**
   ```bash
   git clone https://github.com/shreyamdev/team-conatus-.git
   ```

2. **Navigate into the project folder**
   ```bash
   cd team-conatus-
   ```

3. **Open the project**
   - Simply open the `index.html` file in your browser, or
   - Use a live server extension (e.g., VS Code's "Live Server") for auto-reloading during development.

No additional build steps or dependencies are required since the project uses plain HTML and CSS.
